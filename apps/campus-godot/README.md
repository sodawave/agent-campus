# campus-godot

**Main Agent Campus client** — Godot 4 2D.

- Look: Stardew Valley–like campus (tilemaps, agents, offices).
- Screens: gamification, org/tasks, chats (Godot UI).

- Does not own business rules — talks to Campus API / WS (`CampusEvent`).
