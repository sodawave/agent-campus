# Spec 052 — Visual demo stack

## Objetivo

Seed con `waRoomUrl` + script de review visual. Default: mapa compartido
`~/campus/starter` para ver toda la flota en una sola URL.

## Criterios

- Core seed setea `waRoomUrl` (shared o per-building vía `WA_SEED_MAP_MODE`).
- `scripts/wa/demo-visual.sh` documenta URL + arranque.
- Stack verificable: agentes joined en logs.
