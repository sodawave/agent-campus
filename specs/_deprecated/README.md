# Specs deprecadas

Estas especificaciones corresponden a un **enfoque descartado** del proyecto (build
rechazado, construido sobre un engine heredado que se eliminó). Se conservan solo como
**historia**; no forman parte del flujo de desarrollo activo y **no deben implementarse**.

El proyecto se reconstruye desde cero, spec-first, empezando por `specs/001-campus-core`.

| Spec deprecada | Reemplazo (reconstrucción) |
|---|---|
| `002-campus-core` | `specs/001-campus-core` |
| `001-host-runtime`, `003-campus-api`, `004-command-surface`, `005-ws-transport` | Se re-especificarán como capas posteriores cuando toque, con numeración nueva. |
